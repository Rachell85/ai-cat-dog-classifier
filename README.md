# AI Cat vs Dog Classifier

This project is a simple AI model that classifies whether an animal is a **cat** or a **dog** based on its physical characteristics: height, weight, and length.

## Project Description

The goal is to demonstrate how a basic machine learning model can be trained to distinguish between two classes (binary classification) using only a few numeric features.

This project was created as part of the **Building AI** course by the University of Helsinki and Reaktor.

## Features Used

- Height
- Weight
- Length

## Model

A logistic regression or neural network model is trained on example data and outputs the probability that an input corresponds to a cat or a dog.
